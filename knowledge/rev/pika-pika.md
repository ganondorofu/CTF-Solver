## 問題概要

# Pika-Pika

Pika-Pi-Pikachuuuu

Note: you will get the flag in various parts...join them all by underscores, also replace the spaces by underscores

`difficulty: medium` <br>
`author: cha0s, g1ow, anoninmbus`

## Flag 
```
EH4X{go77a_c4tch_3m_4l1_p0k3m0n_0y3_h0y3_121124}
```

## Solution
* Preffered Editor : hex maniac advance
* decrypt the txt file using a pikalang decryptor
* add pidgey to starter pokemons in scripts.newgame.starters.pokemon
* trade with the trader in oldale town pokecentre
* update the starting money amount to 9999 in scripts.newgame.money
* buy the flag tm from pokemart and teach it to the pikachu obtained from the trainer
* go to petalburg city
* access ROM hacking editors to build a path to the trainer
* change the starter pokemon level to 99 in scripts.newgame.pokemon.level
* beat the trainer to access the 3rd the part of flag
* navigate to 'DE0180' using any hex editor to obtain the final part of flag

## Writeup

# PIKA PIKA WRITEUP

## Steps
1. **Decrypt** `.txt` file using **Pikalang Decryptor**.
2. **Modify Starters:** Add **JIRACHI** in `scripts.newgame.starters.pokemon`.
3. **Trade** in **Oldale Town PokéCenter**. get the pikachu and its name will be the flag part
5. **Set Money:** Change `scripts.newgame.money` to **9999**.
6. **Buy & Teach:** Purchase **Flag TM** and teach it to **Pikachu**.
7. **Reach Petalburg City**.
8. **Boost Level:** Set starter Pokémon to **99** in `scripts.newgame.pokemon.level`.
9. **Defeat Trainer** to get **third flag part**.
10. **Hex Addres:** Go to `DE0180` to retrieve **final flag part**.

11. please note that this challenge was solvable in multiple ways, the writeup addresses the easiest one only
