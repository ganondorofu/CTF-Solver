# Dots & Dashes
Japanese term for key is 'kagi'. 'kagi' is the key to your success. <br>
Flag Format: EHAX{}, put underscores in place of spaces and use all lowercases.

`difficulty: easy` <br>
`author: stellarkp`

## Flag
```
EHAX{m0rs3_v1g3n3r3_0p3r4t10n}
```

## Solution
* Convert the morse code audio to text.
* This text is a ciphertext. The key is given in the description that is 'kagi'.
* Use the Vigenere Cipher method to find the flag and submit it in the format as mentioned earlier.
